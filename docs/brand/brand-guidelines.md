# Neurologue — Brand Guidelines

Neurologue is a local‑first cognitive system.  
Its brand identity should reflect clarity, structure, privacy, and intelligence without feeling corporate or clinical.

This document defines the visual and verbal identity for Neurologue.

---

# 1. Brand Principles

Neurologue’s identity is built on four principles:

### **1. Clarity**
The system organises thinking. The brand should feel clean, structured, and calm.

### **2. Local‑First**
Colours and typography should feel grounded, minimal, and private — not cloud‑centric or flashy.

### **3. Cognitive Depth**
Hints of neural structures, networks, and thought patterns without being literal.

### **4. Approachability**
This is a personal tool. It should feel friendly, not enterprise.

# 3. Logo Usage

Neurologue’s logo is based on the **Neural Dialogue Mark**:

- A stylised “n” formed from two interlocking curves  
- One curve represents neural pathways  
- The other represents dialogue  
- The overlap represents insight  

### **Logo Rules**
- Minimum size: 24px height  
- Clear space: 1× the width of the “n”  
- Do not rotate, distort, or recolour outside the palette  
- Use **Neuro Blue** (`#1C2A3A`) for default  
- Use white for dark backgrounds  
- Use monochrome versions for app icons  

### **App Icon Guidance**
- Use the Neural Dialogue Mark centered  
- Background: Neuro Blue  
- Optional subtle radial gradient from center

# 4. Typography

Neurologue typography should be:

- clean  
- modern  
- readable  
- slightly technical  

### **Primary Typeface**
**Inter**  
- Sans‑serif  
- Highly readable  
- Works well in UI  
- Open source  

### **Secondary Typeface**
**JetBrains Mono**  
- For code blocks  
- For metadata  
- For embeddings/technical views  

### **Type Scale**

| Role | Size | Weight |
|------|------|--------|
| H1 | 28–32px | 600 |
| H2 | 22–24px | 600 |
| H3 | 18–20px | 500 |
| Body | 14–16px | 400 |
| Small | 12–13px | 400 |

---

# 5. Iconography

Neurologue uses a **thin‑line, geometric icon style**.

### Characteristics
- 1.5px stroke  
- Rounded corners  
- Minimal detail  
- No filled icons except for critical states  

### Icon Themes
- Capture → pencil, lightning bolt, inbox  
- Library → grid, list, tag, timeline  
- Processing → nodes, clusters, spark  
- Export → arrow‑out, folder, JSON brackets  

---

# 6. Spacing & Layout

Neurologue’s UI should feel airy and structured.

### **Spacing System**
Use a 4‑point grid:

```
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
```


### **Card Layout**
- 16px padding  
- 12px between elements  
- 24px between sections  

### **Borders**
- 1px Fog (`#D4D4D8`)  
- 6px border radius  

---

# 7. Tone of Voice

Neurologue’s writing style should reflect:

### **Clear**
Avoid jargon unless necessary.

### **Calm**
No exclamation marks in UI.

### **Supportive**
The system helps you think — it doesn’t command.

### **Insightful**
Surface patterns, not noise.

### **Private**
Avoid language that implies cloud or sharing.
