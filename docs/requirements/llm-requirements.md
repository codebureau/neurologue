# LLM Requirements

## Embedding Model
- Must be small and fast
- Must run locally
- Recommended: `bge-small-en`, `gte-small`

## LLM Model
- Must run locally via Ollama
- Must be < 4B parameters for speed
- Recommended: Phi‑3 Mini, Qwen 2.5 3B

## Processing Tasks
- Theme summarisation
- Tag suggestion
- Contradiction detection
- Open loop detection

## Constraints
- No cloud calls
- No external APIs
- No large models
