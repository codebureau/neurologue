# Functional Requirements

## Capture Layer
- Global hotkey opens capture popup
- User can enter text
- User can paste clipboard content
- User can add optional tags
- Entry is saved with timestamp
- No AI processing during capture

## Library Layer
- View raw entries in chronological order
- View entries by tag
- View entries by theme
- Full‑text search
- Semantic search using embeddings
- Entry detail view
- Related entries view

## Processing Layer
- Generate embeddings for new entries
- Cluster entries into themes
- Generate theme summaries
- Suggest tags
- Detect contradictions
- Identify open loops

## Export Layer
- Export raw entries (JSON/Markdown)
- Export themes + summaries
- Export embeddings
- Full export bundle
