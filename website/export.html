Export & Import

Export your corpus to portable CCF snapshots, import from backups, and automate exports on a schedule.

Manual export CCF import Scheduled export External AI tools

Running a manual export

  1. Click the Export… button in the top-right of the library toolbar.

  2. A native folder picker opens. Choose an existing folder or create a new one.

  3. Neurologue writes all five output files to that folder. A toast notification at the bottom-right of the window confirms success, showing the entry and theme counts and the destination path.

Exports are non-destructive — they copy data out of Neurologue's database. Nothing in the app is modified or deleted.

Output files

FileFormatContents
entries.json JSON array All entries with id, content, source, type, created_at, and tags (array of strings)
entries.md Markdown All entries formatted as a single Markdown document — H2 per entry with content, tags, and metadata
themes.json JSON array All themes with id, name, summary, and entries (array of { entry_id, score })
themes.md Markdown All themes formatted as a Markdown document — H2 per theme with summary and member entries
embeddings.jsonl JSONL (one object per line) All entry embeddings: { entry_id, model_name, vector: [768 floats] }

NotebookLM (Google)

Upload entries.md and/or themes.md as sources in a new notebook. NotebookLM can then answer questions about your captured thoughts, generate summaries, and find connections — with citations back to the original entries.

Claude (Anthropic)

Paste or upload entries.md directly into a conversation. Claude handles large documents well. Ask it to find patterns, summarise by theme, or identify contradictions or open questions in your notes.

GitHub Copilot / ChatGPT

Upload entries.json for structured analysis, or entries.md for readability. Useful for asking "what are the recurring ideas in this?" or "what have I been thinking about work lately?".

Custom pipelines

embeddings.jsonl contains the raw vectors in a standard format. You can import these directly into other vector stores (Chroma, Pinecone, Weaviate, etc.) to build your own retrieval pipelines on top of your Neurologue data.

Example entry from embeddings.jsonl:

{"entry_id": "abc123...", "model_name": "nomic-embed-text", "vector": [0.021, -0.014, ...]}

Export scope

Each manual export captures a full snapshot of all entries, themes, and embeddings at the time of export. For automated recurring snapshots, see Scheduled export below.

Importing a CCF snapshot

The same CCF format used for exports can be imported back into Neurologue. This is the recommended way to migrate your corpus between machines or restore from a backup.

  1. Open Settings → Data and click Import CCF…

  2. Select the CCF folder — the folder containing entries.json, themes.json, and the other export files.

  3. Neurologue imports entries and themes from the snapshot. Entries with matching IDs are skipped, so re-importing a snapshot never creates duplicates.

Imported entries appear in the Library immediately. The background worker will embed them on its next tick — watch the Worker indicator in the status bar. Embeddings from embeddings.jsonl are not currently imported; they are regenerated by the worker.

Scheduled export

Neurologue can automatically snapshot your corpus on a regular schedule. Configure this in Settings → Scheduled Export.

How it works

  • Choose Daily or Weekly frequency and a destination folder.
  • Each run creates a timestamped sub-folder (e.g. 2026-05-21T08-00-00/) containing the full set of CCF files.
  • Optionally include a diff.json file listing only entries added or changed since the previous snapshot — useful for change tracking or incremental pipelines.
  • Optionally run adapter transforms automatically after each snapshot to produce additional output formats.

Running a snapshot on demand

Click Export now in the Scheduled Export settings tab to trigger a snapshot immediately, without waiting for the next scheduled run. The result appears in the Export history panel.
