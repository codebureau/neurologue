Export

Export your entire knowledge base to portable files for use with external AI tools.

Running an export

  1. Click the Export… button in the top-right of the library toolbar.

  2. A native folder picker opens. Choose an existing folder or create a new one.

  3. Neurologue writes all five output files to that folder. A toast notification at the bottom-right of the window confirms success, showing the entry and theme counts and the destination path.

Exports are non-destructive — they copy data out of Neurologue's database. Nothing in the app is modified or deleted.

Output files

FileFormatContents
entries.json JSON array All entries with id, content, source, type, created_at, and tags (array of strings)
entries.md Markdown All entries formatted as a single Markdown document — H2 per entry with content, tags, and metadata
themes.json JSON array All themes with id, name, summary, and entries (array of { entry_id, score })
themes.md Markdown All themes formatted as a Markdown document — H2 per theme with summary and member entries
embeddings.jsonl JSONL (one object per line) All entry embeddings: { entry_id, model_name, vector: [768 floats] }

Using the export with external AI tools

NotebookLM (Google)

Upload entries.md and/or themes.md as sources in a new notebook. NotebookLM can then answer questions about your captured thoughts, generate summaries, and find connections — with citations back to the original entries.

Claude (Anthropic)

Paste or upload entries.md directly into a conversation. Claude handles large documents well. Ask it to find patterns, summarise by theme, or identify contradictions or open questions in your notes.

GitHub Copilot / ChatGPT

Upload entries.json for structured analysis, or entries.md for readability. Useful for asking "what are the recurring ideas in this?" or "what have I been thinking about work lately?".

Custom pipelines

embeddings.jsonl contains the raw vectors in a standard format. You can import these directly into other vector stores (Chroma, Pinecone, Weaviate, etc.) to build your own retrieval pipelines on top of your Neurologue data.

Example entry from embeddings.jsonl:

{"entry_id": "abc123...", "model_name": "nomic-embed-text", "vector": [0.021, -0.014, ...]}

Export scope

Each export captures a full snapshot of all entries, themes, and embeddings at the time of export. There is currently no incremental or scheduled export — run it manually whenever you want a fresh copy.
