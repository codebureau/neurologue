What is Neurologue?

Neurologue is a desktop application that lets you capture thoughts, notes, and ideas in under two seconds — no context switching required. In the background it generates vector embeddings of everything you write, clusters related entries into Themes, and gives you semantic search so you can find ideas by meaning rather than exact words.

Everything runs locally. No accounts, no cloud sync, no telemetry. Your data stays on your machine.

After capture, the background worker picks up your entry within 10 seconds, generates a semantic embedding via Ollama, and after every 5 new embeddings automatically re-clusters everything into themes. This happens silently — you don't need to trigger it.

The science in brief

Semantic embeddings

When you save an entry, the background worker passes its text through the nomic-embed-text model running in Ollama. The model converts the text into a 768-dimensional vector — a list of 768 numbers that encodes the meaning of what you wrote, not just the words.

Entries about similar ideas end up with vectors that are close together in this high-dimensional space. Entries about different topics are far apart. This is what powers semantic search: instead of matching keywords, Neurologue finds entries whose meaning-vectors are nearest to your query's meaning-vector.

Automatic clustering into themes

Once entries have vectors, Neurologue periodically runs k-means++ clustering to group similar entries together. The number of clusters is chosen automatically using the formula k = round(√(n/2)), clamped between 2 and 20.

Each cluster becomes a Theme. Neurologue asks the LLM to read the top entries from each cluster and write a short name and summary. Themes update automatically every time 5 new entries are embedded — your mental landscape evolves as you write.

Requirements

RequirementDetails
Operating System Windows 10/11, macOS 12+, or Linux
Ollama Required for embeddings and theme summaries. Download from ollama.com
nomic-embed-text Embedding model (~274 MB). Run: ollama pull nomic-embed-text
phi3:mini LLM for theme summaries (~2.3 GB). Run: ollama pull phi3:mini

Ollama must be running for embeddings, theme summaries, entry categorisation, and tag suggestions to work. The app functions without it (capture and text search still work), but semantic search will fall back to text mode, themes won’t be generated, and categories won’t be auto-assigned.

Quick start

  1. Download Neurologue from the Releases page and run the installer for your platform. No Node.js or npm required.

  2. Install Ollama and pull both models:

    ollama pull nomic-embed-text
ollama pull phi3:mini

  3. Launch Neurologue from your Start menu, Applications folder, or app launcher.

  4. Capture your first thought — press Ctrl+Shift+Space from anywhere, type something, press Ctrl+Enter to save.

  5. Open the library — the main window shows your entry. Wait ~10 seconds for the background worker to embed it. After 4+ entries are embedded, themes will start appearing in the sidebar.

  6. Try semantic search — click Semantic in the toolbar and type a concept. Results are ranked by meaning, not keywords.
