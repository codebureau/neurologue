Library

Browse, search, and explore everything you've captured.

Layout overview

The main library window has three panels side by side:

PanelPurpose
Left sidebarTags (with counts) and Categories for filtering; Themes for navigation
Timeline (centre)Entries matching the current filter or search, with optional grouping and heatmap
Detail (right)Full content of the selected entry — including tags, category, and revision history

Toolbar

The toolbar at the top contains:

  • Search bar — type to search; results update as you type (300 ms debounce). Press Escape to clear.
  • Text / Semantic toggle — switches the search mode (see below).
  • Entry count — shows how many entries match the current view.
  • Export… — opens the export workflow.
  • Maintenance — opens the Tag Management panel.
  • ⚙ — opens the Settings view in the navigation rail.
  • Help — opens this documentation in your browser.

Search modes

Text search

The default mode. Uses SQLite full-text search to match entries whose content contains the words you type. Fast and works entirely offline. Results are paginated — 50 per page, with a Load more button at the bottom.

Semantic search

Click the Semantic button to switch modes. Instead of matching keywords, Neurologue embeds your query using nomic-embed-text and finds the 10 entries most similar in meaning — even if they share no words with your query.

Each result shows a match score from 0.00 to 1.00 — the cosine similarity between your query embedding and the entry embedding. Higher is more similar.

Requires Ollama. If Ollama is not running when you switch to Semantic mode, a notice appears and results fall back to text search automatically.

Tip: Semantic search only returns the top 10 results. If you need to browse more, use Text mode.

Tag filtering

The left sidebar lists all tags with their entry counts. Click any tag to filter the timeline to only entries with that tag. An active filter pill appears above the timeline showing the active tag with a × to clear it.

  • Click the × on the filter pill to remove the tag filter.
  • Clicking a tag pill on an entry card or in the detail panel also applies that tag filter.
  • A tag filter and a category filter can be active at the same time — they combine with AND (entries must match both).
  • A text search can be active on top of both filters simultaneously.

Category filtering

Below the Tags section in the sidebar is a Categories section listing each category with entry counts. Click a category to filter the timeline to only entries of that type. Categories are:

  • Task — something to do or remember to do
  • Thought — a reflection, opinion, or observation
  • Reminder — a time-sensitive note
  • Idea — a creative or exploratory concept
  • Question — something you're wondering about
  • Decision — a choice made or being considered

The category badge on an entry card is also clickable — clicking it applies that category as a filter.

If no category has been assigned yet (Ollama not available during processing), entries appear without a badge and are not counted in any category.

Active filters

When one or more filters are active, a filter bar appears between the timeline controls and the entry list. Each active filter (tag, category) shows as a pill with a × to remove it individually. A Clear all link removes all active filters at once.

Timeline controls

A control bar sits above the entry list with two sets of controls:

Grouping

Choose how entries are grouped in the timeline:

  • None — flat reverse-chronological list (default)
  • Day — entries grouped under a header for each calendar day
  • Week — entries grouped under a header showing the week's date range
  • Month — entries grouped under a month/year header

Activity heatmap

Click Heatmap to toggle a 52-week activity graph above the timeline — similar to a GitHub contribution graph. Each cell represents one day; the colour intensity reflects how many entries were captured that day. Hover any cell to see the exact count and date.

Infinite scroll

The timeline loads 50 entries at a time. When you scroll to the bottom, the next page loads automatically — there is no "Load more" button. All active filters and grouping settings are respected as pages load.

Entry timeline

Each card in the timeline shows:

  • Date/time — when the entry was captured
  • Match score — only in semantic search mode
  • Preview — first ~50 characters of content
  • Category badge — the auto-assigned or user-set category (clickable — applies a category filter)
  • Tag pills — tags shown as small badges (clickable — applies a tag filter)

Click any card to open the full entry in the detail panel. The selected card is highlighted.

Entry detail

Clicking an entry opens its full detail in the right panel, showing:

  • Full content text
  • Source and type metadata (if edited, the edit timestamp is shown alongside the capture time)
  • All tags as clickable pills — clicking a tag applies that tag filter to the timeline
  • Category badge — the effective category (auto or user-set); click the badge to open a dropdown and override it manually
  • Tag suggestions — if Ollama is running, suggested tags appear below the tag editor as pills you can click to add
  • Similar entries — a collapsible section at the bottom of the panel listing conceptually related entries (see below)

Similar entries

At the bottom of every entry's detail panel is a collapsed Similar entries section. Click the header to expand it and see up to 8 entries that are semantically close to the one you're reading.

How similarity is measured

Similarity is based on meaning, not wording. When an entry is saved, the background worker passes its text through the nomic-embed-text embedding model, which produces a 768-dimensional vector encoding the conceptual content of the entry. To find similar entries, Neurologue looks up the stored vector for the selected entry and searches for the nearest neighbours in the vector database — no additional Ollama call is needed.

This means:

  • Two entries can be highly similar even if they share no words in common — what matters is whether they are about the same idea or topic.
  • Entries that share words but are about different things will not be considered similar.
  • Similarity is not sentiment — an anxious note and a calm note about the same topic will still rank as similar.

The similarity percentage

Each card shows a percentage derived from the vector distance between the two entries. It is an approximate indicator — use it as a rough guide rather than a precise score. 80%+ generally indicates strong topical overlap; below 50% the connection may be loose.

Requirements and limitations

  • Only entries that have been processed by the background worker (and therefore have an embedding) can appear in the list. Newly captured entries may not appear until the worker has run.
  • A working Ollama installation is not required to view similar entries — the lookup uses stored embeddings. Ollama is only needed to generate new embeddings for future entries.
  • The section is hidden if no embedding exists for the selected entry, or if no similar entries are found.
  • Result count (currently 8) and similarity threshold are not user-configurable in this version.

Editing an entry

Click the Edit button at the bottom of the detail panel to open an inline edit form. Make your changes and press Save (or Ctrl+Enter) to save. Press Escape or Cancel to discard.

When an entry is saved, the previous content is automatically preserved in the revision history — nothing is permanently lost.

Version history

Click the History button to open the revision history drawer at the bottom of the detail panel. Each row shows when that version was saved and a preview of the text. Click outside the drawer or press the ✕ button to close it.

Tag management

Click Maintenance in the toolbar to open the Tag Management panel. This gives you tools to keep your tags clean and consistent.

Rename a tag

Click Rename next to any tag, type the new name, and press Enter. All entries are retagged automatically.

Delete a tag

Click Delete next to a tag and confirm. The tag is removed from all entries; the entries themselves are not affected.

Merge tags

Use merge when two tags mean the same thing (e.g. ml and machine-learning). In the Possible duplicates section, click Keep on the tag name you want to keep. The other tag is absorbed: all entries that had it are retagged to the kept name.

Duplicate detection

The Possible duplicates section shows pairs of tags that may be duplicates, detected in two ways:

  • Structural — format variants (machine learning vs machine-learning), abbreviations (dev vs development), plural/stem variants (tag vs tagging), and close spelling (Levenshtein distance)
  • Semantic — tags whose embeddings are similar in meaning, above a configurable threshold

If the list is empty, no probable duplicates were found at the current sensitivity level.

Duplicate detection sensitivity

The sensitivity slider (also available in Settings) controls how aggressively semantic duplicates are flagged:

  • Strict — only very similar tags are flagged (fewer false positives)
  • Balanced — default; catches most duplicates without being too noisy
  • Broad — flags loosely related tags (may include false positives)

Other views

The left navigation rail also contains several analysis views. See the Analysis page for full documentation of the Dashboard, Conflicts, Priorities, Knowledge Graph, and Memory Replay views. For AI-powered corpus analysis, see Agents.

Settings

Click the ⚙ icon in the left navigation rail (or the ⚙ button in the toolbar) to open the Settings view. See the Settings page for a full reference of all options: models, tags, hotkey, worker intervals, appearance, data management, scheduled export, and Portfolio.

Status bar

A thin bar at the bottom of the window shows live status for Ollama and the background worker. It updates automatically — you never need to refresh or restart the app to see current state.

Indicators

Each indicator has a coloured dot followed by a short description:

Dot colourMeaning
TealRunning / active — Ollama is reachable, or the worker is running and idle
GoldProcessing — the worker is currently embedding entries
Dim greyStopped / not reachable — Ollama is not running, or the worker has stopped

Ollama indicator

Shows one of:

  • Ollama — nomic-embed-text:latest, phi3:mini (teal dot) — Ollama is running and those models are available
  • Ollama not running (grey dot) — Ollama is not reachable; semantic search and embedding will not work

Worker indicator

Shows one of:

  • Processing (N queued) (gold dot) — the background worker is actively embedding entries; N is how many remain
  • Worker idle — last: Mon DD HH:MM (teal dot) — all entries are embedded; shows when the last one was processed
  • Worker idle (teal dot) — running but no entries have been embedded yet in this session
  • Worker stopped (grey dot) — the worker is not running

Auto-refresh

When the worker finishes embedding new entries, the timeline and tag list refresh automatically — you will see newly captured entries appear without any manual action. When clustering completes and new themes are generated, the themes sidebar also refreshes automatically.
