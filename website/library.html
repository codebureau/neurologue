Library

Browse, search, and explore everything you've captured.

Layout overview

The main library window has three panels side by side:

PanelPurpose
Left sidebarTags and Themes for filtering and navigation
Timeline (centre)Chronological list of entries matching the current filter or search
Detail (right)Full content of the selected entry, or details of the selected theme

Toolbar

The toolbar at the top contains:

  • Search bar — type to search; results update as you type (300 ms debounce). Press Escape to clear.
  • Text / Semantic toggle — switches the search mode (see below).
  • Entry count — shows how many entries match the current view.
  • Export… — opens the export workflow.
  • ⚙ — opens the Model settings panel to change which Ollama models are used.
  • Help — opens this documentation in your browser.

Search modes

Text search

The default mode. Uses SQLite full-text search to match entries whose content contains the words you type. Fast and works entirely offline. Results are paginated — 50 per page, with a Load more button at the bottom.

Semantic search

Click the Semantic button to switch modes. Instead of matching keywords, Neurologue embeds your query using nomic-embed-text and finds the 10 entries most similar in meaning — even if they share no words with your query.

Each result shows a match score from 0.00 to 1.00 — the cosine similarity between your query embedding and the entry embedding. Higher is more similar.

Requires Ollama. If Ollama is not running when you switch to Semantic mode, a notice appears and results fall back to text search automatically.

Tip: Semantic search only returns the top 10 results. If you need to browse more, use Text mode.

Tag filtering

The left sidebar lists all tags across all entries. Click any tag to filter the timeline to only entries with that tag. The active tag is highlighted.

  • Click All entries at the top of the tag list to clear the filter.
  • Click the ✕ next to an active tag to deselect it.
  • You can only have one tag filter active at a time.
  • Applying a tag filter clears any active search query.
  • Clicking a tag in the entry detail panel also applies that tag filter.

Entry timeline

Each card in the timeline shows:

  • Date/time — when the entry was captured
  • Match score — only in semantic search mode
  • Preview — first ~50 characters of content
  • Tag pills — up to 6 tags shown as small badges

Click any card to open the full entry in the detail panel. The selected card is highlighted.

In text search and tag filter views, entries are paginated at 50 per page. A Load more button appears at the bottom when more results exist.

Entry detail

Clicking an entry opens its full detail in the right panel, showing:

  • Full content text
  • Source and type metadata
  • All tags as clickable pills — clicking a tag applies that tag filter to the timeline

Theme sidebar

Below the tag list is a Themes section. This lists all auto-generated theme clusters. Click any theme to open its detail view in the right panel. See the Themes section for more.

Model settings

Click the ⚙ button in the toolbar to open the Model settings panel. From here you can choose which locally installed Ollama models are used for embeddings and theme summaries. The dropdowns are populated from your available Ollama models; any changes take effect immediately on the next worker tick.

Settings are stored in settings.json alongside your database in the app’s user data directory.

Status bar

A thin bar at the bottom of the window shows live status for Ollama and the background worker. It updates automatically — you never need to refresh or restart the app to see current state.

Indicators

Each indicator has a coloured dot followed by a short description:

Dot colourMeaning
TealRunning / active — Ollama is reachable, or the worker is running and idle
GoldProcessing — the worker is currently embedding entries
Dim greyStopped / not reachable — Ollama is not running, or the worker has stopped

Ollama indicator

Shows one of:

  • Ollama — nomic-embed-text:latest, phi3:mini (teal dot) — Ollama is running and those models are available
  • Ollama not running (grey dot) — Ollama is not reachable; semantic search and embedding will not work

Worker indicator

Shows one of:

  • Processing (N queued) (gold dot) — the background worker is actively embedding entries; N is how many remain
  • Worker idle — last: Mon DD HH:MM (teal dot) — all entries are embedded; shows when the last one was processed
  • Worker idle (teal dot) — running but no entries have been embedded yet in this session
  • Worker stopped (grey dot) — the worker is not running

Auto-refresh

When the worker finishes embedding new entries, the timeline and tag list refresh automatically — you will see newly captured entries appear without any manual action. When clustering completes and new themes are generated, the themes sidebar also refreshes automatically.
