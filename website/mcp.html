MCP Server

Expose your note corpus to Claude Desktop, Cursor, and other AI tools via the Model Context Protocol.

What is MCP?

The Model Context Protocol (MCP) is an open standard that lets AI assistants call tools hosted by local or remote servers. Neurologue's MCP server runs locally alongside the app and gives external clients read/write access to your corpus through six tools.

The MCP server binds to 127.0.0.1 only — it is not reachable from other machines on your network. A bearer token provides additional protection for local processes.

Enabling the server

  1. Open Settings → MCP Server.

  2. Check Enable MCP server. A bearer token is auto-generated — copy it for the config snippets below.

  3. Optionally change the port (default 3737).

  4. Click Save settings. The status line confirms the server is running.

The server starts automatically on the next app launch when enabled. To rotate the token click Regenerate and save again.

Connecting Claude Desktop

Click Copy Claude Desktop config in Settings, then paste the result into your claude_desktop_config.json:

PlatformConfig file location
macOS~/Library/Application Support/Claude/claude_desktop_config.json
Windows%APPDATA%\Claude\claude_desktop_config.json

The config snippet looks like this (substitute your actual token):

{
  "mcpServers": {
    "neurologue": {
      "url": "http://127.0.0.1:3737/mcp",
      "headers": {
        "Authorization": "Bearer <your-token>"
      }
    }
  }
}

Restart Claude Desktop after saving. The Neurologue tools will appear in the tool picker inside any conversation.

Connecting Cursor

In Cursor → Settings → MCP, add a new server entry:

{
  "neurologue": {
    "url": "http://127.0.0.1:3737/mcp",
    "headers": {
      "Authorization": "Bearer <your-token>"
    }
  }
}

Available tools

Tool Description
search_notes Search notes by text and semantic similarity. Returns matching entries with tags and dates.
list_themes List all detected themes with entry counts and descriptions.
get_theme_entries Return the notes assigned to a named theme (partial name match).
create_note Create a new note in the corpus, optionally with tags. The note is automatically queued for embedding and classification.
summarise_topic Retrieve relevant notes and ask the local LLM (via Ollama) to synthesise a summary. Requires Ollama to be running.
run_agent Run a built-in Neurologue agent (daily-digest, weekly-review, monthly-themes) and return its full output.

search_notes

Combines full-text (SQLite LIKE) and semantic (vector) search, deduplicates results by entry ID, and returns up to limit matches (default 10). Results include the date, tags, and up to 200 characters of content per note.

list_themes

Returns all themes currently detected in your corpus. Themes are generated automatically by the background clustering worker. If no themes exist yet, run the clustering agent first.

get_theme_entries

Accepts a partial theme name and returns the notes assigned to the best match. Up to limit entries (default 20) sorted by relevance score.

create_note

Creates a note with source: "mcp" so it is identifiable in the corpus. Tags are normalised to lowercase. The entry is queued for background embedding automatically.

summarise_topic

Uses semantic search to find the limit most relevant notes (default 5), then calls the configured Ollama LLM to produce a summary. Falls back to text search if Ollama embeddings are unavailable.

run_agent

Streams the full agent output and returns it as a single string. Available agent IDs:

  • daily-digest — summary of today's entries
  • weekly-review — themes and highlights from the past week
  • monthly-themes — cluster analysis for the past month

Security

The server only listens on the loopback interface (127.0.0.1) and is not reachable from other machines. The bearer token adds a second layer of access control for local processes.

To rotate the token: open Settings → MCP Server, click Regenerate, save, and update your client config files with the new token.
